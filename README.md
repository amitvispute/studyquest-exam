# StudyQuest — AI-Powered 11+ Exam Preparation App

A full-stack web application built to help children prepare for the 
UK 11+ grammar school entrance exam, using AI to generate 
practice questions, track progress, and provide coaching support.

## What it does

- Generates practice questions across Maths, English, Verbal 
  Reasoning and Non-Verbal Reasoning
- Tracks scores across multiple mock exam sessions and shows 
  progress over time
- Uses the Claude API to provide AI-generated feedback and 
  coaching on weak areas
- Supports parent and student views with separate dashboards
- Built for the Trafford Grammar Schools Consortium exam format

## Tech Stack

- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend & Database:** Supabase (PostgreSQL + Auth)
- **AI:** Claude API (Anthropic)
- **Built with:** Lovable (AI-assisted development)
- **Testing:** Playwright
